# tvOS asset provenance

The tvOS layered icon and Top Shelf image were generated locally on 2026-09-04
from SunPad's existing repository-owned iOS icon
`apple/ios/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.

- Background layers: simple blue-to-turquoise gradients created locally.
- Middle layers: transparent spacing layers for the tvOS parallax stack.
- Foreground layers: scaled copies of the existing SunPad icon.
- Top Shelf image: the existing SunPad icon centered on the same local gradient.

No game image, extracted game asset, save, or banner artwork was used.
